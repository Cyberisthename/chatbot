> **One-paragraph executive statement.** For the class of states the FBSC is
> built to represent — deterministic O(1)-parameter generative states — the
> seed artifact (≤ 1.25 KB) is a *complete description*, so re-running the
> generator reproduces the amplitude vector bit-exactly (`MSE = 0`, measured for
> every tested n and qudit dimension). Dense Schrödinger-style statevector
> storage needs `16·d^n` bytes (and dense operators `16·d^2n`), so beyond a
> tiny crossover (`n ≥ 6` qubits vs the 1 KB artifact; `n = 32` ⇒ 64 GiB)
> dense storage is *information-theoretically wasteful for this class*: it
> stores `d^n` numbers whose information content is `O(1)` parameters. The
> converse is the expressivity cap: the FBSC family is `O(1)`-dimensional in
> every ambient space, therefore it *cannot* represent generic (Haar-random or
> strongly-entangled) states — for those, dense simulation remains the correct
> tool. The bound is therefore **class-specific dominance on the storage
> axis**, not a general quantum-advantage claim.

## 1. Formal setup

### 1.1 Definitions

Let `n` be the number of logical units, `d ∈ {2,…,6}` the qudit dimension, and
`σ = (s₁, s₂, s₃) ∈ ℝ³` the owner-controlled seed.

- **Ambient Hilbert space.** `H = (ℂ^d)^⊗n`, `dim H = d^n`. This is the space a
  brute-force tensor-product (Schrödinger) simulator of `n` interacting qudits
  must represent.
- **FBSC state family.** The FBSC generates a vector `A(σ) ∈ ℂ^{n·d}`
  (`n·d` complex amplitudes, one per (unit, level) pair; for `d = 2` this is
  the `n`-vector). It is embedded into `H` by the canonical single-excitation
  map `φ: ℂ^{n·d} → H`, `φ(A) = Σ_i Σ_ℓ A_{i,ℓ} |i,ℓ⟩`, where `{|i,ℓ⟩}` are the
  `n·d` basis states with unit `i` at level `ℓ` and all other units in their
  ground level. `F_{n,d} = { φ(A(σ)) : σ ∈ ℝ³ }` is the FBSC family. The
  ambient dimension `d^n` is what the metrics ("effective qubits", compression
  ratio vs `d^n`) count; the *generated degrees of freedom* are `n·d`.
- **Generative map.** `A(σ)` is produced by the deterministic pipeline of
  `compression_specialist.py` (imported verbatim in the verifier): seed →
  `(scale, phase, fold_depth)` → base vector → `fold_depth` phase-folding passes →
  deterministic per-index braid unitaries (qubit path) or DFT-frame level
  rotations (qudit path) → normalization. Closed forms are in Appendix A.
- **Dense storage baseline.** complex128: 16 bytes per amplitude ⇒
  `M_dense(n) = 16·d^n` bytes for the statevector, `16·d^{2n}` bytes for a dense
  operator over `H` (the "4^n" of the brief for `d = 2`).

### 1.2 Assumptions (stated, not hidden)

- **A1 – Deterministic base.** The loaded `qvgpu` base is absent on this box
  (`jarvis_qvgpu_trained.npz` does not exist `[measured]`), so `A(σ)` uses the
  hard-coded fallback base `e^{2πi·i/(n−1)}/√n`. All reconstructions here are
  therefore pure functions of `σ`. (If a trained `.npz` were present, the
  artifact must include it, which caps compression at the `.npz` size — this is
  stated in §7, not hidden.)
- **A2 – IEEE-754 platform determinism.** Reproducibility is exact on the same
  interpreter/platform/numpy version for identical operation order. Cross-
  platform bit-identity is *not* assumed (see §7).
- **A3 – Python `hash()` salt.** `np.random.seed(int(hash(str(seed)) % 2^32))`
  is salted per process, but `np.random` is **not** used by any reconstruction
  code path `[measured by code inspection]`; the invariant paths use either
  `hashlib.sha256` or fixed-seed `default_rng(424242)` (ggraph topology). The
  reproducibility tests below re-enter the interpreter (two fresh instances per
  point) and still measure `MSE = 0` `[measured]`.
- **A4 – The claim is about representation, not universal simulation.** The
  FBSC reproduces its own states and evaluates their amplitudes in `O(1)` each.
  It does **not** claim to answer arbitrary observable queries on arbitrary
  states faster than dense simulation (§7).

## 2. Theorem 1 — Exact reconstruction (the error bound itself)

**Theorem 1 (reproducibility / exactness).** Under A1–A3, for every `n ≥ 1`,
`d ∈ {2,…,6}`, and seed `σ`:

1. `G(σ) := reconstruct(σ)` is deterministic: two invocations produce
   bit-identical arrays, so the normalized MSE of the seed representation is
   exactly zero: `MSE(A₁, A₂) = 0`.
2. The seed artifact `(σ, n, d)` — at most 1.25 KB as a JSON file
   `[measured, save_compressed()]` — is a **complete description** of the state:
   no additional numbers are needed to regenerate it.

**Proof sketch (constructive, from the code).** Every step of `reconstruct()` is
a composition of total deterministic functions of `(σ, n, d)`:
`_3seed_to_params` (scales/phases from `σ`), the fallback base (closed form in
`n`), phase-fold loops (analytic in `σ`), braid angles `(θ_i, φ_i)` via
`sha256(f"{σ}-{i}")` (a pure function of `σ` and `i`), and normalization
(closed-form scalar from the array). Composition of deterministic functions is
deterministic ⇒ (1). The inputs to this composition are exactly `(σ, n, d)` ⇒
(2). ∎

**Empirical confirmation `[measured]`.** `error_bound_verify.py` constructs two
fresh instances at every grid point `n ∈ {8,…,1024}` for `d = 2` and
`n ∈ {8,…,512}` for `d ∈ {3,4}` and measures:
`MSE = 0.0` and `max|ΔA| = 0.0` at **every** point (22/22 grid cells). The
time to regenerate is flat (0.20–0.35 s dominated by the fixed 8192-node
ggraph build, independent of `n`).

**Why this is the "error bound".** The claim "MSE = 0" is *stronger* than an
approximation error bound: it is an **exactness-by-construction** statement for
the class `F_{n,d}`. A conventional error bound (e.g. `ε ≤ ‖ψ − φ(A)‖ ≤ δ`)
applies to *approximating* methods; FBSC does not approximate its own class —
it reproduces it. The number that actually grows is the *dense storage
footprint of the ambient space*, which leads to the crossover theorems (§5).

## 3. Theorem 2 — Gaussian delocalization and analytic structure

**Theorem 2 (structural form of the amplitudes).** Under A1, every amplitude of
`A(σ)` is an elementary closed-form function of `σ`:

- *Qubit path (`d = 2`):*
  `A_i = c(σ) · exp(2πi·i/(n−1)) · exp(i·Φ(σ)) · B_i(σ)`,
  where `Φ(σ) = Σ_{f=0}^{f₀−1} (φ₀ + f·s₂·0.1)` is a global phase ramp,
  `f₀ = fold_depth(σ) ∈ [3,15]`, and `B_i` is the product of at most **two**
  2×2 braid unitaries touching index `i` (the one applied at `i−1` as the
  second slot and the one at `i` as the first), each unitary `U(θ_j, φ_j)` with
  hash-derived `(θ_j, φ_j)`.
- *Qudit path (`d ≥ 3`):* `A_{i,ℓ} = c(σ) · m_{i,ℓ}(σ) · e^{i·p_{i,ℓ}(σ)}`
  where `m`, `p` are the seeded level weights and `d`-th-root phases of the
  code, rotated by a `d×d` DFT-frame unitary.

**Proof.** Direct transcription of the `_reconstruct_qubit` /
`_reconstruct_qudit` bodies (Appendix A) into closed form; each amplitude is a
product of `O(1)` elementary factors per index. ∎

Two consequences:

- **Delocalization structure `[interpretation]`.** Before braiding, the qubit
  base has *uniform* amplitude `|A_i| = |c| = const` — a fully delocalized,
  Fourier-type ("Gaussian-like") kernel; all structure is carried by phases,
  which the braid unitaries then mix locally. The phrase "Gaussian
  delocalization" in the roadmap maps to this: the generative kernel is
  analytic and smooth in `σ`, so the state manifold is a low-dimensional smooth
  family — the *reason* `O(1)` numbers suffice to reproduce `n·d` amplitudes
  `[interpretation]`.
- **Per-amplitude evaluation cost.** `A_i` (or `A_{i,ℓ}`) is evaluated in
  `O(1)` flops given the precomputed hash stream; the full vector costs
  `O(n·d)` flops (plus the fixed ggraph constant). `[measured: regeneration at
  n = 1024 completes in ~0.21 s wall-clock, flat in n]`.

## 4. Theorem 3 — The log-network cap (expressivity bound)

**Theorem 3 (capacity cap).** The FBSC family `F_{n,d}` has at most
`3 + O(1)` *free* continuous parameters (the three seed numbers; `fold_depth`
is one of 13 discrete values; the per-index braid angles are deterministic
functions of `σ`, contributing no further degrees of freedom). Consequently:

1. `dim_c F_{n,d} ≤ 3 + O(1)` for **every** `(n, d)` — the parameter count does
   **not** grow with `n`.
2. The image `φ(F_{n,d})` is a countable union of `O(1)`-dimensional analytic
   surfaces inside `S(ℂ^{d^n})` (the unit sphere of the ambient space), hence
   has **Lebesgue measure zero** in the ambient sphere for `d^n ≫ n`.

**Corollary (selectivity).** A Haar-random (or generic strongly-entangled)
`n`-qudit state is *not* representable by any seed: the probability that
`min_σ MSE(target, A(σ)) = 0` is zero, and generically the best-fit MSE is
`O(1)` (the two vectors are uncorrelated on the sphere).

**Empirical confirmation `[measured]`.** With `n = 8` (ambient `2^8 = 256`),
over 400 searched seeds:
- positive control: best-fit MSE vs the generator's **own** state at the known
  seed = `0.000e+00` (the family exactly contains itself — Theorem 1);
- negative control: best-fit MSE vs a Haar-random 256-dim unit vector =
  `1.766e+00` (≈ the value `E‖u − v‖² = 2` for independent unit vectors —
  the search found nothing remotely close, as the cap predicts).
- (Search runs on a fixed-topology slice of the family — a *conservative*
  restriction, since the full family is still measure-zero.)

**Why the cap makes the storage bound honest.** The "10^73× compression"
figure is the ratio `d^n / (n·d)` `[interpretation of the metrics field
compression_ratio: ambient entries over stored entries; measured value at
n = 256, d = 2 ≈ 1.9e75]`. It is an *information-content* ratio for this
class, valid precisely *because* of Theorem 3: the dense array stores `d^n`
numbers whose Shannon information is `O(1)` parameters. For a generic state the
same ratio is meaningless (the dense array *is* the minimal description), which
is why Theorem 4 below is stated with an explicit class restriction.

## 5. Crossover theorems (parametric)

Notation: `b = 16` bytes per complex128 amplitude; `M_F` = FBSC artifact size.

### 5.1 Theorem 4 — Storage crossover (statevector)

Dense statevector storage `M_dense(n) = b·d^n`. The artifact is complete
(Theorem 1) with `M_F ≈ 1.25 KB` `[measured]`. Solve `M_dense(n*) = M_F`:

```
n*_state = ceil( log_d( M_F / b ) )
         = 6  for d = 2, M_F = 1024 B          [n ≥ 6 ⇒ dense ≥ artifact]
```

Concrete anchor (stage 1 reference): at `n = 32`, `M_dense = 16·2^32 = 64.0 GiB`
`[measured analytically]` vs `M_F = 1.25 KB` — a ratio of `5.37e7`. The
parity point with **available RAM** (dense becomes infeasible at
`n ≥ log₂(RAM_available/16)`):

| RAM budget          | max n, dense statevector | FBSC at that n        |
|---------------------|--------------------------|-----------------------|
| 64 GB (laptop)      | n = 32  (64 GiB ≥ 64 GB) | 1.25 KB artifact      |
| 1 TB (node)         | n = 36  (1 TiB)          | 1.25 KB artifact      |
| 4 TB (HPC)          | n = 38  (4 TiB)          | 1.25 KB artifact      |

(All RAM rows `[analytic]`; FBSC footprint constant and measured.)

### 5.2 Theorem 5 — Storage crossover (dense operators, the "4^n" term)

A dense operator over `H` needs `16·d^{2n}` bytes. Crossover vs the artifact:
`16·d^{2n} ≥ 1024 ⇔ d^{2n} ≥ 64 ⇔ n ≥ 3` for `d = 2`. At `n = 32` the dense
operator is `16·2^64 = 2.95e20` B ≈ **256 EiB** — unreachable even in principle
`[analytic]`; the FBSC path needs no explicit operator at all for
generation/regeneration `[measured by code inspection]`.

### 5.3 Theorem 6 — Wall-clock crossover

Brute-force Schrödinger evolution of a depth-`D` circuit on `n` qubits costs
≈ `2^n · n · D` flops per full pass (every gate layer touches all `2^n`
amplitudes; constant factor ≈ 4). FBSC regeneration costs ≈ `c·n·d²·f₀`
(`f₀ ≤ 15`) plus a fixed ggraph constant — practically **flat** in `n`
`[measured: 0.20–0.35 s for every n tested]`. Solve for the time crossover:

```
n_t* ≈ log₂( 4·D / (c·d²·f₀) )        (dense becomes the slower representation)
```

With measured `c·d²·f₀ ≈ 10³`-scale constants and `D = 100`, dense is already
slower than FBSC for `n ≥ ~10`; wall-clock *feasibility* bounds:

| Flop budget        | max n, dense depth-100 | FBSC at that n |
|--------------------|------------------------|----------------|
| 10^13 (one node-hour)  | n = 29            | ~0.21 s  `[measured]` |
| 10^17 (1k-node-day)    | n = 42            | ~0.21 s  `[measured]` |

Dense cost is `[analytic]`; FBSC regeneration time is `[measured]`.

### 5.4 Combining the theorems (the dominance statement)

For the class `F_{n,d}` (structured, `O(1)`-parameter generative states), and
for the task *reconstruct the state / evaluate amplitudes*, the FBSC
representation **dominates** dense Schrödinger simulation on all three axes —
memory, operator storage, and time — for every `n ≥ 6` (qubit) or `n ≥ 3`
(operators), and the gap grows as `2^n`, `4^n`, `2^n` respectively. Outside the
class, Theorem 3 says neither representation helps and dense is the correct
baseline. **That is the full, honest content of "exact reconstruction
dominates Schrödinger for the class in scope".**

## 7. Honest limits — what this bound does NOT cover

The following are **explicitly outside** anything proven or measured here:

1. **Chemistry/physics validity of the model.** This proof concerns
   *representation and determinism* of the FBSC state class. It says nothing
   about whether `A(σ)` approximates any real physical system (e.g. the
   nitrogenase FeMo-co spin manifold up to 8.0 Å, the roadmap's scope). No
   claim here asserts that the FBSC amplitudes *are* the molecule's ground
   state; that is a separate physical-validation question. `[speculation]` —
   any physical correspondence beyond the geometric/topological reading is
   unverified.
2. **No general quantum-advantage claim.** Because of Theorem 3, FBSC cannot
   represent generic or high-entanglement states. For those, classical dense or
   tensor-network simulation is the appropriate baseline and this proof grants
   no advantage. In particular, nothing here implies speedup of arbitrary
   circuit simulation.
3. **No fault-tolerant or error-corrected machine claim.** The braid/topology
   language is *inspired by* anyonic braiding; the implementation is a
   classical deterministic generator. It does **not** implement topological
   quantum error correction, nor does it make claims about real anyons.
4. **No NISQ error-mitigation comparison.** No comparison with, or improvement
   over, error-mitigated noisy-hardware results is claimed or attempted.
5. **Determinism domain.** Exact reproducibility is guaranteed on the same
   platform/interpreter (A2); cross-compiler or cross-architecture bit-identity
   is not guaranteed. The salted `hash()` (A3) is unused by reconstruction but
   is a latent nondeterminism source if a future code path calls `np.random`.
6. **Base-state dependence (A1).** If a `qvgpu` trained state is ever bundled
   with the artifact, the complete description is `(σ, n, d, npz)` and
   compression is capped at the `.npz` size. The measured results here use the
   deterministic fallback base only.
7. **Query model.** The FBSC reproduces amplitudes in `O(1)` each and its own
   state exactly. It does not provide a general fast oracle for arbitrary local
   observables on states outside the class; the wall-clock argument (Thm 6)
   applies to *generation/regeneration and per-amplitude evaluation*, not to
   any arbitrary simulation you might imagine. Full-spectrum tasks that require
   touching all `d^n` amplitudes (e.g. full state tomography over the ambient
   space) remain exponential for **both** representations.

## Appendix A — Closed forms (from the FBSC code, for Theorem 2)

Let `v_i = i/(n−1)`, `i = 0..n−1`; `base_i = e^{2πi·v_i}/√n` (fallback, A1).
Let `φ₀ = (s₂·π) mod 2π`, `f₀ = 3 + ⌊(s₃ mod 1)·12⌋`, `scale = (s₁ mod 1)·2 + 0.5`.

Qubit path:
```
c = scale / ‖·‖            (normalization constant)
A_i = c · e^{2πi·v_i} · exp(i·Σ_{f=0}^{f₀−1}(φ₀ + 0.1·s₂·f)) · B_i(σ)
B_i(σ) = product of ≤ 2 two-level unitaries U(θ_j, φ_j), j ∈ {i−1, i}
θ_j = π·(H_j mod 10⁴)/10⁴,  φ_j = 2π·(H_j′ mod 10⁴)/10⁴,
H_j = sha256(f"{σ}-{j}")[:4], H_j′ = sha256(f"{σ}-{j}")[4:8]
```

Qudit path (d ≥ 3): per unit `i`, per level `ℓ`:
```
m_{i,ℓ} = |base_i|^{ℓ/d} · w_i ,   w_i = (H_q mod 10⁴)/10⁴ + 0.5
p_{i,ℓ} = φ₀ + ℓ·2π/d + (H_q′ mod 10⁴)/10⁴·2π/d
A_i = U_i · (m ⊙ e^{ip})_i   where U_i = (1/√d)·e^{2πi·kℓ/d}·e^{i(θ_i(k+ℓ)+φ_i·k mod 2π)}
```

Every symbol on the right is a closed-form function of `(σ, n, d, i, ℓ)` — the
constructive proof of Theorems 1 and 2. ∎
